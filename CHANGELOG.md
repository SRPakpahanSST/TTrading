## [1.0.0] - 2026-09-15

### ✨ Added (Ditambahkan)
- **Dashboard** — Ringkasan portofolio, skor 4 pilar, deteksi 7 dosa, mantra harian
- **Mode Simulasi** — Latihan trading dengan saldo virtual Rp 10.000.000
- **Jurnal Trading** — Catat transaksi, refleksi, emosi, dan pilar yang digunakan
- **Analisis** — Grafik Bull-Bear (MA200), aliran dana asing, screener saham
- **7 Dosa Dagang** — Deteksi & latihan mengatasi 7 dosa (Keserakahan, Ketakutan, Harapan, Penyesalan, Kesombongan, Keraguan, Kebingungan)
- **Meditasi Trading** — Timer 5 menit, cek emosi, mantra harian
- **Kalkulator** — Hitung lot, stop loss, take profit, dan amal 2%
- **Amal** — Catat donasi, total amal, riwayat amal
- **Pengaturan** — Profil, target profit, max drawdown, komitmen amal, notifikasi
- **Dark Mode** — Dukungan tema gelap/terang
- **Responsive Design** — Tampilan optimal di HP, tablet, dan desktop

### 🎨 Design
- Palet warna: Amber (#F59E0B), Slate (#1E293B), Green (#22C55E)
- Logo maskot "T" dengan dua tangan menopang dan tunas hijau
- Banner/header dengan matahari terbit dan candlestick
- Font: System UI / Inter
- Animasi: Fade in, pulse alert

### 🏗️ Technical
- **Frontend**: React 18 + Vite 5
- **Styling**: Tailwind CSS 3
- **State Management**: Zustand 4
- **Routing**: React Router DOM 6
- **Chart**: Recharts 2
- **Date**: date-fns 3
- **Storage**: localStorage (sementara)
- **Deploy**: GitHub Pages (via GitHub Actions)

### 📚 Documentation
- `README.md` — Dokumentasi utama proyek
- `LICENSE` — MIT License
- `CONTRIBUTING.md` — Panduan kontribusi
- `CODE_OF_CONDUCT.md` — Kode etik komunitas
- `CHANGELOG.md` — Catatan perubahan versi

### 🧪 Testing
- Unit test untuk kalkulasi trading
- Integration test untuk jurnal & deteksi dosa
- E2E test untuk dashboard

### 🔒 Security
- Semua data disimpan di localStorage (sementara)
- Tidak ada data yang dikirim ke server (belum ada backend)
- Sertifikasi keamanan akan ditambahkan saat migrasi ke Vercel + Supabase
